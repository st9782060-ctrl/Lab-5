## 1. Відповіді на ключові питання

1. **Які є види циклів?**  
   У мові програмування C++ є три види циклів:
   * `for` — цикл із параметром (лічильником);
   * `while` — цикл із передумовою;
   * `do ... while` — цикл із післяумовою.

2. **Різниця між `while` та `do ... while`?**  
   * У циклі **`while`** умова перевіряється **перед** виконанням тіла циклу. Якщо умова одразу хибна, тіло циклу не виконається жодного разу.
   * У циклі **`do ... while`** умова перевіряється **після** виконання тіла циклу, тому тіло циклу гарантовано виконається хоча б один раз.
